# NTrail API

[Смотреть на Gitbook](https://borisoffficial.gitbook.io/ntrail-api/)

## Зачем?

Множество интернет сервисов использует авторизацию через социальные сети и знают аккаунты своих пользователей, но извлечь из этого практическую информацию, приносящую пользу бизнесу не так то просто.

У различных социальных сетей свои способы авторизации запросов, множество методов для получения информации непосредственно из их баз данных. Таким образом, существуют случаи, когда выгоднее обращаться непосредственно к API определенного сайта

#### Когда стоит использовать API конкретной социальной сети?

1. Оно есть. Не все мессенджеры, социальные сети или другие ресурсы, хранящие информацию о людях предоставляют публичный доступ к API
2. Вам необходимы сырые данные, например список друзей, посты на стене и прочее

#### Когда лучше воспользоваться NTrail API?

1. Когда у ресурса нет открытого API, а NTrail его предоставляет и поддерживает
2. Нет времени чтобы самостоятельно изучать тонкости взаимодействия с социальной сетью, ее ограничения на количество запросов, получение авторизованного доступа, поиск необходимых методов и адаптация для вашей задачи
3. Нужны сложные, агрегированные параметры, которые выводятся методом некоторых расчетов и с помощью выполнения большого количества запросов

#### Что если необходимого функционала еще нету?

Написать в [поддержку](https://t.me/fiobond). По договоренности, нужные вам параметры  будут добавлены. Также может быть добавлена поддержка новых медиа ресурсов, требующихся вашему бизнесу
