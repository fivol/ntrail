# ВКонтакте

### /vk/user/

#### basic

Это самые простые значения, собираются непосредственно со страницы. Большинство из них представлено в документации [VK API](https://vk.com/dev/fields)

| Название поля | Описание | Тип |
| :--- | :--- | :--- |
| id | ID пользователя | integer |
| url | Ссылка на профиль | string |
| name | Имя и фамилия если есть | string |
| username | Ник | string |
| sex | Пол: male, female, not specified | string |
| birth | Дата рождения в формате _DD.MM_ или _DD.MM.YYYY_ | string |
| photo | Ссылка на аватарку 200 на 200 | string |
| age | Возраст в годах, если указан на странице | float |
| platform.type | С какой платформы производился вход: _web, android, apple_ | string |
| friends.count | Количество друзей | integer |
| followers.count | Количество подписчиков | integer |
| subscriptions.count | Количество подписок | integer |
| occupation | Занятие, указанно на странице: _work, school, university_ | string |
| university | Университет со страницы | string |
| school | Школа | string |
| active\_user | Является ли активным пользователям. Недавно был онлайн | boolean |

#### connections

Для получения этих значений проанализированы друзья человека, подписки и подписчики. Некоторые поля повторяют предыдущую таблицу, но отличаются способом их получения. Алгоритм сравнивает и выбирает наиболее релевантное значения, таким образом может быть исправлена ложная информация, указанная автором страницы. Некоторые свойства автор не заполнил, тогда они получены в обход

| Название поля | Описание | Тип |
| :--- | :--- | :--- |
| age | Возраст, полученный из возрастов друзей | float |
| city | Город проживания | string |
| country | Страна | string |
| school | Школа, исходя из социального графа человека | string |
| social.groups.all.count | Количество социальных кластеров. Кластер - группа людей, имеющая более крепкую внутреннюю связь, чем внешнюю. Например рабочий коллектив, класс в школе, смена в лагере и прочее | integer |
| social.groups.big.count | Количество крупных кластеров. Размер более 8 | integer |
| social.groups.small.count | Количество маленьких кластеров. Размер не более 8 | integer |
| social.groups.free.count | Количество случайных знакомств. То есть людей в друзьях, не состоящих не в одном кластере \(коллективе\). Это значение характеризует поведение человека в жизни и в сети | integer |
