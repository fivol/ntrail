# NTrail-core
Репозиторий с библиотекой для высокоуровнего 
доступа к объектам в социальных сетях. 
Опирается на [ntrail-worker](https://github.com/fivol/ntrail-worker)
и обстрагирует обращение к API и парсинг сайтов за методами классов.

Например класс VKUser отвечает за пользователя вк, предоставляет 
методы `friends()`, `groups()`, `posts()` и прочие, `VKCommunity` за 
любое сообщество людей и так далее. Все классы наследуются от базовых, 
что сложены в папку core/modules
