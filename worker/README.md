# NTrail Worker
Вычислительная еденица. Делает запросы на API различных социальных сетей, других сервисов. 
Использует модули, каждый из которых заточен на собственное API. 
Задача проста - выполнить пришедшие запросы, никакого анализа, просто сделать это быстро и вернуть результат.
Каждый запрос атомарен, то есть уже должен содеражать всё необходимое в себе - метод, токен, параметры и тд 

## Фичи
1. Единый интерфейс взаимодествия с API других сервисов
1. Кеширование результатов
1. Распределение запросов по ядрам, потокам. Максимальное быстрое выполнение банча

## Использование
1. Как импортируемый модуль, которому можно передать партию запросов, он его выполнит
1. Как сервер, есть протокол взаимодействия. Можно запускать на множестве машин
